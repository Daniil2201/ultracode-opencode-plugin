# Spec-First

Спецификация до кода. Применяй перед любой задачей, где есть хоть малейшая неясность.

## Когда применять

- Новое поведение, неясные границы, несколько способов решения.
- Всегда — если задача планируется через `/bolt`.

## Что делать

1. Спроси цель (одна-две строки) и выбери kebab-case `<slug>`.
2. Создай `spec/<slug>.md`: Цель / Интерфейс (вход-выход, файлы) / Acceptance (проверяемые условия) / Запреты.
3. Зафиксируй: `ultracode_context action=add kind=decision text="spec/<slug> для цели <goal>"`.

## Чего не делать

- Не пиши код без spec-файла, если задача идёт через `/bolt`.
- Не складывай spec в `.gitignore` — коммитится вместе с кодом.
