Спецификация до кода (SDD). Не писать код, пока нет spec-файла.

> `ultracode_context action=budget profile=conservative` — профиль порогов этой сессии (перетирает ручные, приоритет за последним вызовом).

## Usage

```
/spec <цель> [slug]
```

## Instructions

1. Спроси пользователя, что делаем (goal задачи, одна-две строки).
2. Выбери короткий kebab-case `<slug>` (спроси, если неясно).
3. Создай файл `spec/<slug>.md` в корне проекта:
   - **Цель** — одна-две строки.
   - **Интерфейс** — что входит/выходит, какие файлы трогаются.
   - **Acceptance** — проверяемые условия (`exit 0` команды, поведение, файл существует).
   - **Запреты** — что нельзя делать (например, «не трогать `farm/`»).
4. Не пиши код, пока spec-файл не создан.
5. После создания — `ultracode_context action=add kind=decision text="spec/<slug> для цели <goal>"`.
6. `spec/` коммитится вместе с кодом (в `.gitignore` не добавлять).
