description: "Дорабатывает TZ.md: вопросы по дырам, точечные правки"
---

> `ultracode_context action=budget profile=balanced`

## Usage

```
/tz-refine
```

## Instructions

1. Прочитать `TZ.md`. Если нет — сказать «сначала /tz-init».
2. Прочитать скилл `skills/tz-review/SKILL.md`.
3. Найти 3 самые критичные дыры (по критериям скилла).
4. Задать пользователю **до 3 вопросов** по этим дырам. По одному на дыру, коротко.
5. Дождаться ответов. Не додумывать.
6. После ответов — точечно отредактировать соответствующие разделы `TZ.md`. Не переписывать файл целиком.
7. Если дыр больше 3 — упомянуть остальные в конце: «осталось N дыр, вызови /tz-refine ещё раз».
8. Записать в `ultracode_context action=add kind=decision` факт «TZ.md обновлён, раздел X».
