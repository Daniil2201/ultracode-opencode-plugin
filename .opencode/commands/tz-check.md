> `ultracode_context action=budget profile=balanced`

## Usage

```
/tz-check
```

## Instructions

1. Прочитать `TZ.md` в корне проекта. Если нет — сказать «TZ.md не найден, сначала /tz-init».
2. Прочитать скилл `skills/tz-review/SKILL.md` — критерии хорошего ТЗ.
3. Пройти по разделам шаблона и проверить каждый: заполнен / пусто / частично / противоречит другому разделу.
4. Отдельно проверить: есть ли «Границы», есть ли приоритеты (must/should), есть ли acceptance по ключевым сценариям, есть ли этапы AFD.
5. **Ничего не править.** Только отчёт.
6. Отчёт — в чат, компактно: таблица раздел / статус / замечание. В конце — список из 3–5 самых критичных дыр.
7. Предложить: «исправить через /tz-refine или вручную».
