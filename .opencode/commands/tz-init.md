---
description: "Создаёт TZ.md из шаблона в текущем проекте"
---

> `ultracode_context action=budget profile=balanced`

## Usage

```
/tz-init <название-проекта>
```

## Instructions

1. Аргумент команды — название проекта (например, `destroyers`). Если пусто — спросить.
2. Проверить: есть ли `TZ.md` в корне текущего проекта. Если есть — не перезаписывать, сказать «TZ.md уже существует, используй /tz-check для проверки».
3. Прочитать шаблон: сначала `.opencode/templates/tz.md` (локальный), если нет — `~/.config/opencode/templates/tz.md` (глобальный).
4. Подставить `{{NAME}}` из аргумента, `{{DATE}}` — сегодня, `{{AUTHOR}}` — git config user.name или «пользователь».
5. Записать в `TZ.md` в корне проекта.
6. Ответить: «TZ.md создан. Открой его, скопируй содержимое в ИИ в браузере, обсуди проект, вставь результат обратно. Потом — /tz-check».
